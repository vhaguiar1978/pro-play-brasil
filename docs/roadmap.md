# Roadmap de Desenvolvimento

## Objetivo

Construir o sistema por etapas, colocando primeiro o que faz a operacao funcionar e deixando automacoes avancadas para a sequencia.

## Etapa 1 - Fundacao

- definir identidade visual e nome final do sistema
- criar projeto base
- configurar banco de dados
- criar login com perfis
- criar layout com menus por permissao

## Etapa 2 - Cadastros essenciais

- materias-primas
- categorias
- produtos
- vendedores
- clientes
- parceiros de producao

## Etapa 3 - Operacao comercial

- pedidos
- calculo de totais
- parcelamento
- geracao de contas a receber
- envio de pedido por WhatsApp com texto pronto

## Etapa 4 - Operacao interna

- producao
- comissoes
- contas a pagar
- fluxo de caixa
- dashboard principal

## Etapa 5 - Inteligencia e crescimento

- relatorios
- CRM de novos produtos
- prospeccao no Google Maps
- mapa de clientes
- cobranca automatica
- chat interno

## Etapa 6 - Recursos com IA

- tratamento de imagem
- fundo branco
- melhoria de iluminacao
- imagem promocional com caes
- identificacao de produto por foto

## MVP recomendado

Se a meta for comecar rapido, o MVP ideal deve incluir:

- login por perfil
- dashboard
- materia-prima
- produtos com composicao e custo
- clientes
- vendedores
- pedidos
- parcelamento
- contas a receber
- comissao basica

## Resultado esperado do MVP

Com esse primeiro bloco, voce ja consegue:

- cadastrar produtos corretamente
- saber custo e preco sugerido
- registrar clientes e vendedores
- criar pedidos
- controlar parcelas
- acompanhar recebimentos
- calcular comissoes principais
